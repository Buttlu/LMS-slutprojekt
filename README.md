Ett LMS (learning management system) i C# .NET 10. All data är mock.

Login:
Lärare login:
* email: `teacher@test.com`
* lösenord: `password`

Elev login:
* email: `elev@test.com`
* lösenord: `password`

Lärare kan skapa kurser, moduler för de kurserna, och inlämningar för de modulerna. Lärare kan också se alla kurser och elever i hela systemet. 
<br>Elever kan se sin egen kurs och dens moduler och inlämningar. Elever kan också bara se sina lärare och klasskompisar.
